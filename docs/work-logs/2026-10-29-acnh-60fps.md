# ACNH 3.0.1 selectable 30 / 60 FPS

## User request

> 帮我适配一下60帧，并在设置中可调，锁帧30和60

## Implementation

Work continues on `acnh`, with source base
`8736f3d7864d00e4efd197101b1ca60392157c9f` plus the local changes recorded here.
The Display settings page offers 30 FPS and 60 FPS (experimental), remembers the
choice in `Animal Crossing Data/frame-rate.txt`, and states that restarting is
required. The default remains 30. The running mode stays unchanged until exit;
the next launch loads code and parameter corrections together. Unsupported
builds, including 1.2.1, retain their original timing. The 3.0.1 presentation
policy caps normal output at 30 or 60 with a 60 Hz VI clock.

An optional, original host adapter consumes pinned local data from
[tmouh/acnh-60fps](https://github.com/tmouh/acnh-60fps), commit
`e5e03e64739334c9fbd36f19658b98e805f8ba8d`, licensed CC BY-NC 4.0.
Its six input file hashes, adapter fingerprint, options and generated file
hashes are recorded in the local FPS manifest. No external mod source/tools are
executed or vendored into the repository. The local source and its path/hash
manifest remain under ignored
`game-assets/animal-crossing-new-horizons/mods/v3.0.1/`.

The adapter validates the original NSO and rewritten main hashes and all 6,417
replacement sites, rejecting any rewriter collision. The native loader checks
all original words before any write, applies the corrections in mapped memory,
then seals executable memory before the game starts. Original modules and RomFS
remain unchanged on disk. Four separately checked RomFS overlays supply the
parameter corrections. The host replaces the external SDK display enabler with
its native presentation policy. The packager verifies matching runtime/asset
identities, includes all FPS assets in its existing build receipt, and includes
the external license and attribution in the local app.

Loading a copy of the owner's island exposed OLSC command 14
(`SetSaveDataBackupSetting`). The host now accepts disabling backup for the
valid local account as an offline no-op, rejects enabling it, and still rejects
unknown commands. The request layout was checked against the original 3.0.1
client. Service tests cover this path. This was needed to reach the island for
the frame-rate checks.

No other cheats were enabled. MetalFX interpolation remains unavailable in the
panel. Shader/pipeline contribution and project-star actions remain omitted.
All code, tools and tests stay within `games/acnh/`; no commit, push, PR, DMG or
installation outside `build/` was included in the initial implementation task.
The subsequent local commit request is recorded below.

## Handoff and limits

Final app: `build/acnh-3.0.1/Animal Crossing New Horizons.app`. Press 1, open
Display, choose 30 or 60 FPS, then quit and restart. The existing owner's saved
60 FPS selection is preserved; a fresh preference defaults to 30. Test artifacts
remain ignored under `build/acnh-3.0.1/work/fps-tests/`.

60 FPS is fixed-rate and experimental. Sustained performance below the target
can slow frame-counted actions. No exhaustive activities, interiors, menus,
cutscenes, online play or long-session save compatibility pass was performed.
The existing 3.0.1 graphics limitations remain; a successful CPU loader probe
does not establish full gameplay correctness. A full 1.2.1 app was not rebuilt;
only its synthetic version guard was tested.
