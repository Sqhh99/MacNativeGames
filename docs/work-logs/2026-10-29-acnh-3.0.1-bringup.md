### Post-introduction crash reported on 2026-10-29

The owner's interactive test completed the introductory movie. The log shows
both movie decoders reaching end of stream without decode errors, followed by
`sm: service "pctl" not implemented`. The original SDK call is
`nn::pctl::IsFreeCommunicationAvailable()` at `sdk+0x40a8a0`, reached from
`main+0x1b921cc`. Added its host mapping to the local unrestricted parental-control
policy; network reachability remains independently offline. The symbol-map test
exercises the returned Boolean to prevent falling through to the SDK IPC path.

Preserved the crash log and a profile snapshot under
`build/acnh-3.0.1/work/crash-records/20261029-033827/`. The profile contains local
account and pipeline metadata but no committed game save; do not imply that the
uncommitted character/island choices survived the crash. Copied the preserved
account and pipeline/shader cache into the regular sibling `Animal Crossing Data`
directory without overwriting differing existing files. The unit suite, rebuilt
host loader probe (including four real pctl import calls), and CPU startup probe
pass after this correction. Full post-movie gameplay replay remains unverified.
