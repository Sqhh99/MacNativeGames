## 2. 1.2.1 compatibility review
Every change in `main...acnh` under `games/acnh` was read for its effect on a 1.2.1 build.

**Already safe:**
- The version-specific code is compiled per version (`ACNH_VERSION_RAW`):
  - the 1.2.1 game patches;
  - NVN 53.312 vs 55.15;
  - the 3.0.1 loader probe.
- `expected-v458752.json` and `preparation-v458752.json` are unchanged.
- The packager's 1.2.1 rewritten-module hashes now come from `preparation-v458752.json`. They were checked to equal the three values that were hard-coded before.
- MetalFX upscaling still defaults to off without the launcher's old `=0` settings (`totk_mfx_up.m`: an unset variable means off).
- `ipc.c` registers no fsp-srv, pctl, caps, acc, nifm, ssl, nsd, hid or applet services. So any SDK call the new host functions answer would have stopped a 1.2.1 game before; they cannot replace a working path.

**Fixed (`f7f4473`):**
- **Shadowed handlers.** `system_applets.c` is consulted before the other override tables. It repeated `nn::err::ShowError(Result)` and `nn::pctl::IsFreeCommunicationAvailable`, which `applet_host.c` answers for 1.2.1, so it would have replaced 1.2.1's handlers. The duplicates were removed. `test_each_name_has_one_table` checks that no `system_applets.c` name appears in another table.
- **Old work folders.** A native work folder made before 3.0.1 support has no `build/version-config.h`, and `make` would have stopped. The Makefile now writes 1.2.1's for it, and refuses a folder with no host tables.
- **Builds outside Git.** `package_native_app.py`'s `git rev-parse` was fatal, so a non-Git source archive could not package. The commit is now optional.
- **Seed label.** `prepare_shader_seed.py` labelled every seed "3.0.1"; the label now comes from the prepared folder.

**Shared behaviour changes, disclosed in the PR:**
- the new default keys;
- key 1 opens the panel;
- keys 2–4 are no longer shortcuts. Upstream's ACNH key 3 and key 4 called stubs that return 0 (`game_patches.c`). Key 2 cycled interpolation, which made 0 frames on 3.0.1; 1.2.1 was not measured.
