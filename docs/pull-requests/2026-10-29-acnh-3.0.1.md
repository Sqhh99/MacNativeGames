## Summary
This adds **Animal Crossing: New Horizons 3.0.1** next to the verified **1.2.1**, as an experimental target. The build picks the version from the update's verified metadata, and 1.2.1 keeps its pins, patches and behaviour.

For players of both versions, it also adds:
- a keyboard and mouse layout made for this game;
- the tabbed settings panel from #1210, with key-binding drawings;
- a shader seed that removes the frame drops the first time a scene is drawn;
- the app icon;
- fixes for the crashes I hit while playing 3.0.1.

Everything is under `games/acnh/`, except the version cell of the ACNH row in the root README (English and Chinese).

Why I made this, as a player of 3.0.1:

**The keys.** The old layout was a fixed test layout. Keys 2–4 were debug shortcuts, and the mouse did nothing. Animal Crossing has no camera to aim, so the mouse only needs to click. The left hand should reach everything else.

**The frame drops.** The game ran at a steady 30 fps, then stopped for up to several seconds whenever something new appeared. In a 10-minute session, 26 frames took over 50 ms:
- 25 of them were spent compiling shaders met for the first time;
- that was 17.9 s of the 19.2 s lost;
- the worst frame took 6.1 s.

**The crashes.** 3.0.1 kept stopping at the same places. Some examples:
- right after the intro movie;
- clicking the mailbox once the tent was up;
- moving into the candidate row of the Chinese (Pinyin) keyboard while entering my name.

Because of the crashes, the game never reached its first save, so every launch started the tutorial again.

## Versions: how 3.0.1 is added without touching 1.2.1
- **Picking the version.** `prepare.py` takes base 1.0.0 with update 1.2.1 (`v458752`) or 3.0.1 (`v2097152`), chosen from the update's verified CNMT. `assets/expected-v2097152.json` pins 3.0.1's ExeFS, NSO segments, RomFS and Control data. Unknown builds are still refused.
- **Compiling for it.** `build_host.py` writes `build/version-config.h`, and `runtime/game_version.h` compiles the runtime for that one version. The packager refuses a runtime built for another version (`MNG_ACNH_VERSION` marker), and 3.0.1 gets its own data folder (no import of old saves).
- **1.2.1-only code stays 1.2.1-only:**
  - the game-address patches (`acnh_ctx_lock`, `acnh_ui_patch`, `acnh_draw_hook`) and NVN 53.312 are compiled only for 1.2.1;
  - 3.0.1 gets NVN 55.15 and a loader probe that calls its post-movie pctl import.
- **1.2.1 pins are unchanged.** `expected-v458752.json` and `preparation-v458752.json` are untouched. The packager's 1.2.1 rewritten-module hashes now come from `preparation-v458752.json`; I checked that they are the same three values that were hard-coded.
- **New host functions can't change a working 1.2.1 path.** Each SDK call this PR answers would otherwise go to a Switch service this host never registers (fsp-srv, pctl, caps, acc, nifm, ssl, nsd, hid or the applets), which stops the game. So on 1.2.1 they can only replace a stop.
  - Two names 1.2.1 already answers in `applet_host.c` keep their existing handlers: `nn::err::ShowError(Result)` and `nn::pctl::IsFreeCommunicationAvailable`.
  - A test checks that the new table repeats no other table's name.
- **Existing 1.2.1 work folders still build.** `build_host.py` now reuses an existing work folder after rechecking it. A folder made before this PR has no `version-config.h`; it is always 1.2.1, so `make` writes 1.2.1's.

**Changes 1.2.1 players will notice.** These are on purpose and shared by both versions:
- the new default keys (below);
- key 1 opens the settings panel instead of the key reminder;
- keys 2–4 are no longer shortcuts:
  - key 2 cycled MetalFX frame interpolation, whose hooks look for Tears of the Kingdom's passes. On 3.0.1 it made 0 interpolated frames out of 2,100; 1.2.1 was not measured. The panel shows interpolation as not available.
  - keys 3 and 4 called functions that do nothing in this game.
- The launcher no longer forces `TOTK_MFX_UPSCALE=0` / `TOTK_MFX_OUTPUT=0`, so the panel's Picture row can switch MetalFX upscaling. The default is still off.

## What changed for players
**Keyboard and mouse layout.** The left hand stays on the keys, and the mouse clicks:

| Action | Switch | Keys | Mouse |
|---|---|---|---|
| Move | left stick | W A S D | |
| Camera | right stick | arrow keys | |
| Talk, use the tool, confirm | A | Space | left button |
| Cancel; hold to run | B | Shift, Esc | |
| Pockets | X | Tab, I | |
| Pick up | Y | E | right button |
| NookPhone | ZL | Q | |
| Reactions | ZR | R | |
| L / R buttons | L / R | Z / C | |
| Stick presses | L3 / R3 | Control / V | |
| + / − buttons | + / − | M or Return / Backspace | |
| Tool ring | d-pad up | 3 | wheel click |
| Put the tool away | d-pad down | 5 | |
| D-pad left / right | d-pad left / right | 2 / 4 | side buttons 4 / 5 |

Scripted input (`commands.txt`, `TOTK_INPUT_SCRIPT`) keeps the old fixed layout, so test scripts mean the same keys.

**Settings panel** (key 1, or L3 + R3 on a controller). It is adapted from #1210 for this game, and its choices are saved next to the app in `Animal Crossing Data`.
- **Display:**
  - the overlay and an FPS graph;
  - the frame rate, shown as this game's own 30 fps (it cannot run faster, so there is nothing to lock);
  - frame interpolation, shown as not available yet;
  - the picture: 1080p, or 1080p with MetalFX upscaling;
  - the game language: follow the Mac, or one of the game's 14 languages, from the next launch.
- **Input:** the controller type and rumble.
- **Key bindings:** drawings of the keyboard and mouse and of the controller. Click a key or button and pick its action; a list view is also available, and each device has its own reset.
- **Left out:** aspect ratio (this game has no aspect patch), and the shader-contribution and star buttons (this game has no shader-list contribution flow).

**Shader seed** (`tools/prepare_shader_seed.py`, optional). It translates the shaders in the player's own game files with the pinned `totk_xlate`:
- 3.0.1: 6,470 shaders plus 1,455 shadow-map variants, 0 failures, about 35 s and 450 MB;
- it stays in the work folder, and nothing is committed;
- the packager checks every file's hash and bundles it, and the app imports it and warms it at start.

Measured results:
- the seed covers 81% of the shader variants my sessions met;
- in a test session, 69 shaders were translated during play instead of 206;
- the first launch on an empty cache compiles everything before the title (210 s on my Mac);
- later launches reach the first frame in about 1 s.

**App icon** (`tools/extract_app_icon.py`, optional). It is made from the update's own title icon, read with `prepare.py`'s checked Control RomFS reader. After packaging, the app is re-registered with Launch Services so the Finder shows the new icon.

## Crashes fixed (3.0.1)
| Where | What the log said | Cause | Fix |
|---|---|---|---|
| Right after the intro movie | `sm: service "pctl" not implemented` | `nn::pctl::IsFreeCommunicationAvailable` went to the SDK's IPC | Answered locally (allowed); the loader probe calls the real import |
| Clicking the mailbox once the tent is up | `sm: service "pctl" not implemented` | `nn::pctl::CheckFreeCommunicationPermission` | `runtime/system_applets.c`: allowed |
| Pinyin name entry: moving up into and past the candidate row | `FATAL … unsupported NVN stage 2` | The candidate list (`Swkbd/shader/*Ocean*`) draws with a geometry shader, and Metal has none | `nvn_mtl.m`: a program with a geometry or tessellation stage is marked unsupported, logged once, and its draws are skipped, as untranslated programs' draws already are. It no longer ends the game. |
| Saving and the setup steps | (calls into an unanswered fs service) | `fs::Commit(name, CommitOption)`, device save size and extension (NACP 0x6f00000, up to 0x24000000), restore flag, `RenameDirectory`, `GetDirectoryEntryCount` | `fs_host.c`; `probe-save` grows to 28 checks |
| 3.0.1 start-up | missing services and NVN version check | `olsc:u`, user count and listing, inactivity state, NVN 55.15 | `olsc_host.c`, `account.c`, `applet_host.c`, `hle_nvn.c` |

An audit then listed every SDK function `main` and `subsdk0` import that no host table names, and added host versions for the ones single-player play can reach:
- **Account:** `OpenUser`, `ListQualifiedUsers`, `PromoteQualification`, and the online-licence dialog (logged).
- **Album:** screenshots taken with the in-game camera are saved as PNG in `Animal Crossing Data/Screenshots`.
- **Applets:** the error dialog (three forms) and the eShop page are logged.
- **Profile picture:** a generated profile image.
- **Controller:** `hid::MergeSingleJoyAsDualJoy`.

Network-only calls now answer "unavailable" instead of stopping: `nifm` local mode and IP config, five `ssl` calls, and `nsd::ResolveEx`. `tests/test_acnh_host_imports.py` checks every one of these names.

## Known limitations
- 3.0.1 stays **experimental**: start-up, the intro, setup and the island arrival are verified; most of the game is not.
- I did not check separately whether the first automatic save (end of the first day) completes.
- Not covered:
  - local wireless play (`nn::ldn` commands not checked);
  - online play;
  - a controller (none was connected in my test sessions; the panel and drawings were checked without one);
  - DLC.
- Visual gaps that are logged, not fixed:
  - the geometry-shader effects of the name keyboard's candidate list are not drawn;
  - logic op and alpha test are not implemented on Metal.
- Frame interpolation is not available in this game yet: it needs ACNH-specific scene, depth, camera and UI hooks.
- With a seed, the first launch on an empty cache waits a few minutes before the title.
